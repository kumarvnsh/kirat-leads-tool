## Operating notes

The Mac app's WebKit store is separate from browser/Pages storage. Use JSON backup/import to migrate. Setup handles project dependencies; Node 20+, Python 3.11+ and Apple Command Line Tools are prerequisite runtimes for rebuilding on another Mac. A signed-in current Codex CLI is required for automated research. The compiled app is for the current Mac architecture. The installer rebuilds for its host architecture. Research needs internet and consumes existing subscription usage.
