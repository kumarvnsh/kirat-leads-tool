# Kirat Lead Tool

Read README.md for the local workflow. Research outputs and local state belong in .local/ or research/, both ignored by Git. Never publish them.

For a research batch: export the current dashboard register, run the prompt command with it and any discovery candidates, then research with available web tools. No web tools means stop and use the documented manual handoff. Save one bounded batch; validate it with `node bin/kirat.js validate FILE`. The user imports and reviews it. Do not write to an Artifact inbox or directly into browser storage.

Prefer up to five source-backed opening/expansion/renovation/rebranding opportunities, approximately three national retail and two NCR. Keep unknowns unknown. Seek projects/fit-out/expansion/regional/marketing managers; do not default to CEO/MD/chairman/founder. No outreach or signed-in LinkedIn automation.

Run `npm test` and `npm run build` after changes. Keep lead-core.js ASCII. Deploy only the build allowlist; preserve sales fields during duplicate merges. Browser storage belongs to the current origin and browser, not a cloud account.
